# Trinity Health Care Clinic Record Track

## 1. Project Description
Trinity Health Care Clinic Record Track is a web-based Management Information System prototype designed to improve the recording, storage, retrieval and management of clinic information.

The system aims to make it easier for clinic staff to manage patient records and other clinic activities.

## 2. Project Objectives
- To improve the storage and management of patient records.
- To make patient information easier to retrieve.
- To improve the recording of consultations and treatments.
- To support the management of patient follow-ups.
- To improve the security and confidentiality of clinic information.

## 3. Technologies Used
- HTML – Web page structure.
- CSS – Website styling.
- JavaScript – Website interactivity.
- PHP – Server-side programming.
- MySQL – Database management.
- XAMPP – Local development server.

## 4. Main Project Files
- `index.php` – Main entry page.
- `auth.php` – User authentication.
- `config.php` – Database configuration.
- `followups.php` – Patient follow-up section.
- `import_patients.php` – Patient data import.
- `includes/` – Supporting project files.

## 5. Installation and Setup
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL.
4. Create the project database in phpMyAdmin.
5. Import the database tables.
6. Configure the database connection in `config.php`.
7. Open the project in a browser using the appropriate localhost address.
